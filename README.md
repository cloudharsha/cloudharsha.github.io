# cloudharsha.github.io

GitHub Pages user site. Hosts the public policy pages that app stores require.

- `privacy-policy.md` → <https://cloudharsha.github.io/privacy-policy/> — the privacy policy for the
  **Get Your Cert** Android app (`com.harshareddy.getyourcert`). This URL is referenced from the
  Google Play listing and must stay live for as long as the app is published. Website changes never
  go here.
- `website-privacy-policy.md` → <https://cloudharsha.github.io/website-privacy-policy/> — the
  separate policy for the **Get Your Cert website** (`get-your-cert.web.app`), which has optional
  Google sign-in and Firestore sync that the app does not. Linked from the website's footer.

This repo must stay **public** — Pages on a private repo requires a paid plan.
